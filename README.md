# Darus Salaam Mosque Website

This is a simple static website suitable for free hosting on GitHub Pages.

## Files
- `index.html` - website content
- `style.css` - design and mobile layout
- `script.js` - mobile menu and current year
- `assets/logo.png` - mosque logo

## Publish FREE with GitHub Pages
1. Sign in to GitHub.
2. Create a new public repository named `YOURUSERNAME.github.io`.
3. Upload all files from this folder, keeping the `assets` folder.
4. Commit the files.
5. Open `https://YOURUSERNAME.github.io`.

## Update prayer times
Open `index.html`, search for `Prayer Times`, and replace each `—` with the correct jama'ah time.

## Add online donations
In `index.html`, find `Ask About Donating` and replace its `href` with your Stripe, PayPal, JustGiving, GoFundMe or other donation-page link.

## Custom domain
If you want to use `darussalaam.uk`, GitHub Pages supports a custom domain. Configure the domain in:
Repository → Settings → Pages → Custom domain
and update the DNS records with your domain provider.
